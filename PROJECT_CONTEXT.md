# Проект "Diplom" (Contract Analysis System)

## Описание
Система автоматизированного анализа текстов контрактов для выявления рискованных операций на основе сравнения цен в контрактах с рыночными индикаторами (бенчмарками).

## Стек технологий
- **Backend:** Java 21, Spring Boot 4.0.4, Spring Data JPA.
- **Frontend:** React (SpotCheck.jsx).
- **Database:** PostgreSQL.
- **NLP Service:** Python (предоставляет эндпоинт для извлечения сущностей из текста).

## Архитектура
1. **Frontend (React):** Пользователь загружает текст контракта.
2. **Backend (Spring Boot):** 
   - Получает текст контракта.
   - Отправляет его в **NLP-сервис** (Python) для извлечения объектов (наименование, количество, цена, единица измерения).
   - Сравнивает извлеченные цены с рыночными показателями из БД.
   - Рассчитывает процент отклонения.
   - Помечает операции как "высокорискованные", если отклонение > 20%.
   - Сохраняет историю контрактов и логи анализа в БД.

## Основные эндпоинты (AnalysisController)

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/analysis/spot-check` | Анализ текста контракта. Принимает `AnalysisRequest` (текст) и `bin` (БИН). |
| `GET` | `/api/analysis/contracts` | Получение истории всех проверенных контрактов. |
| `GET` | `/api/analysis/risks` | Получение списка всех операций с высоким уровнем риска. |
| `POST` | `/api/analysis/market-data` | Обновление/добавление рыночной цены для конкретного товара. |

## Модели данных
- **Contract:** Основная запись о проверенном документе (БИН, дата).
- **ExtractedItemEntity:** Позиции, извлеченные из текста контракта (наименование, количество, цена).
- **MarketIndicator:** Рыночные бенчмарки для различных товаров.
- **BenchmarkLog:** Результат сравнения позиции контракта с рыночным индикатором (процент отклонения, флаг риска).

## Внешние зависимости
- **NLP Service URL:** `http://localhost:8000/extract` (ожидает `POST` с телом `{"text": "..."}`).
